## <b>Frontend</b> | How To Run 
___
1. Setelah anda berhasil up build docker compose terdapat container yang saya beri nama <b>*vue_frontend* </b>. Cek di container yang sedang jalan jika running otomatis frontend sudah jalan di port 5173.
2. Tinggal akses di browser http://localhost:5173
